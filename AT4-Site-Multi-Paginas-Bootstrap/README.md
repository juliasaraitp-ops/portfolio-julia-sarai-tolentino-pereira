# 🎬 Desenvolvimento de Site Multi-página com Bootstrap 5

## 📝 Descrição do Projeto
Este projeto consiste no desenvolvimento do site institucional **Lar de Patas**, um site de 5 páginas sobre **Adoção e Bem-Estar Animal**, com guia de cuidados, funcionamento de abrigos e incentivo à adoção responsável. 
Desenvolvido como parte da disciplina de **Desenvolvimento Front-End Para Web (2026.2)**, o site usa Bootstrap 5 para garantir responsividade, hierarquia de conteúdo e uma experiência fluida para os usuários.
**Páginas do site:** 
* `index.html`: página inicial, com carrossel de destaques e resumo do propósito do site. 
* `sobre.html`: contextualização do tema, organizada com o sistema de Grid do Bootstrap. 
* `galeria.html`: galeria com 6 ou mais cartões (cards) e modais com informações extras. 
* `dados.html`: tabela estilizada e perguntas frequentes em formato sanfona (accordion). 
* `contato.html`: formulário de contato e feedback. 
Todas as páginas compartilham a mesma barra de navegação (navbar) e o mesmo rodapé (footer). 

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5, CSS e JavaScript (via componentes do Bootstrap) 
* **Framework:** Bootstrap 5 (via CDN) 
* **Ferramentas:** VS Code, Git e GitHub 
* **Modelo de IA:** Claude AI

## 📊 Resultados e Aprendizados
* A aplicação atingiu excelente adaptação em diferentes tamanhos de tela (smartphones, tablets e desktops) utilizando o sistema de Grid do Bootstrap.
* Conquistei total domínio na estruturação de um site com múltiplas páginas interligadas por uma navbar e rodapé padronizados, configurando corretamente os caminhos relativos para garantir o funcionamento perfeito no deploy do GitHub Pages.
* Implementação bem-sucedida de elementos avançados do framework, incluindo carrossel de destaques na página inicial, cards responsivos na galeria de animais, tabela estilizada, sanfona (accordion) de perguntas frequentes e formulário de contato estruturado.
* Aprendi a modularizar o design utilizando um arquivo ⁠style.css⁠ próprio para ajustes visuais complementares de paleta de cores e tipografia, aplicando customizações refinadas sem interferir na estrutura base do Bootstrap.

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial Claude AI estritamente como ferramenta de suporte tecnológico para a identificação e correção de erros pontuais (como pequenos bugs de sintaxe, verificação de caminhos relativos e ajustes em tags). Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
