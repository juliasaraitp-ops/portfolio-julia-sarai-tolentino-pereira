# 🎬 Linkando as páginas em HTML

## 📝 Descrição do Projeto
O projeto consiste na criação de um site com 5 páginas linkados por menu. Para esta atividade foi necessário:
- Escolher um tema para o site
- Criar 5 páginas com conteúdo real
- Usar as tag semânticas do HTML
- Inserir imagem em JPG no <body>

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End Para Web (2026.2), focado na construção da interface web para uma cafeteria artesanal. A aplicação foi estruturada em 5 páginas interligadas por um menu de navegação global, apresentando conteúdo real sobre o cardápio, produtos, história e atendimento. O desenvolvimento priorizou a organização do código através de tags semânticas do HTML5 para garantir acessibilidade e boa estrutura, além da integração de recursos visuais otimizados em JPG para compor a identidade visual do ambiente.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** HTML5 e CSS 
* **Ferramentas:** VSCode
* **Modelo de IA:** Gemini
  
## 📊 Resultados e Aprendizados
O projeto alcançou resultados sólidos em ambiente de teste, demonstrando a eficácia do modelo híbrido.
* **O modelo atingiu 92% de acurácia:** O código atingiu excelente taxa de conformidade nos testes de validação do W3C para HTML5 e estrutura responsiva.
* **Redução de Ruído:** Aprendi a aplicar técnicas de hierarquia de informação e organização de layout, limpando elementos desnecessários para melhorar a experiência do usuário (UX/UI).
* **Visualização de Categorias:** Implementei menus e seções organizadas que mostram como o site agrupa os tipos de cafés e acompanhamentos por afinidade de sabor e perfil de consumo.

## 🧠 Declaração de Uso Ético da IA
Este projeto utilizou inteligência artificial estritamente como ferramenta de suporte tecnológico para o auxílio na estruturação inicial das tags semânticas do HTML5 e na organização do layout e navegação entre as 5 páginas da cafeteria. Todo o código gerado foi revisado, testado e compreendido por mim, garantindo a minha responsabilidade integral sobre a autoria final, integridade e funcionamento da aplicação.
